# WEBP_to_PNG_Converter
This script converts all .webp files found in a specific local folder into .png files, saving them in the same folder and giving a summary when it is finished.
I find it useful because sometimes I save many photos about series and movies for nostalgia, and it is annoying that the Windows Photos app ignores the webp files.
All you need to do is to install Python + the Pillow library and edit the FOLDER_PATH to your desired folder to process.
